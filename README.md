# 돌봄 점검 루프 POC (careloop-poc)

복지용구 · 장기요양 서비스에서 고객이 떠나는 두 지점(등급외 결과, 구매 · 대여 뒤)을 **"때가 되면 다시 묻는" 장치**로 막는 아이디어를, 돈 들이지 않고 눌러 볼 수 있게 만든 시제품(POC: Proof of Concept, 개념 검증)이다.

> 이로움돌봄 서비스 개선 제안을 위해 만든 **개인 시제품**이다. (주)티에이치케이컴퍼니와 관계없고, 회사 로고 · 실제 고객 데이터를 쓰지 않는다. 모든 이름 · 번호 · 대화는 가상이다.

## 무엇을 보여 주나
- 등급외 결과 화면에서 **말로 · 글로 · 사람과** 상담 고르기
- 규칙으로 움직이는 **AI 상담원(모의)**: 위급 신호는 즉시 사람에게, 규정 밖 질문은 먼저 묻고 원하면 사람에게
- 대답을 **A~G로 분류**해 반품 · A/S · 사업소 전달 같은 기존 기능으로 잇기(모의)
- **3개월 · 6개월 재연락 일정**을 계산하고 "시간 앞당기기"로 그날의 전화 · 알림톡을 보여 주기(모의)
- **골든셋 시험**: 위급 놓침 0건 · 규정 밖 직접 답 0건 · 분류 90% 이상 · 날짜 계산 100%

## 실행
```bash
python -m http.server 8010 --directory site      # → http://localhost:8010
node --test tests/                               # 규칙 · 일정 · 가명 처리 · 골든셋 · 드리프트 점검 시험
```
- 음성 상담은 크롬에서만 동작한다(브라우저 내장 음성 인식). 다른 브라우저는 글로 상담한다.
- 서버 · 유료 API · 실제 전화 · 알림톡을 쓰지 않는다(비용 0원).

- **한계:** 골든셋을 규칙과 같은 사람이 만들었다. 그래서 점수가 높게 나오는 것이 당연하다. 실제 운영에서는 사람 콜 100건의 실제 대답으로 골든셋을 다시 만든다. 대답은 규칙 기반이라 자유로운 대화는 못 한다(ADR-0001).
