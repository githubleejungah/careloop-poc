# ADR-0003 90 · 180일 재연락은 가상 시계로 시연한다

- 날짜: 2026-11-19 · 상태: 승인(2026-11-19)

## 결정
POC 안에 **가상 시계**(`clock.js`)를 두고, 모든 날짜 계산과 발송 판단은 진짜 시계가 아니라 가상 시계를 본다. 운영 화면의 "시간 앞당기기" 버튼으로 하루 · 1주 · 90일 · 180일을 건너뛴다(AC-66).

## 이유
- 90일 · 180일을 실제로 기다릴 수 없다.
- 날짜 규칙(요일 · 공휴일 · 야간 금지 · 7일 대기 · 2주기 멈춤)을 시험에서 시각을 고정해 정확히 확인할 수 있다(AC-70).

## 대안
- 서버 스케줄러: 서버가 필요해 비용 0원 원칙(ADR-0001)과 맞지 않는다.

## 결과
- 화면 맨 위에 "지금(가상): 2026-11-19 19:00"을 늘 보여 줘 시연 중임을 알린다.
- 실제 운영에서는 가상 시계 자리에 서버 시계와 스케줄러가 들어간다.
