# ADR-0001 POC는 정적 사이트 + 규칙 기반 상담원으로 만든다

- 날짜: 2026-11-19 · 상태: 승인(2026-11-19)

## 결정
POC는 서버 없이 정적 사이트(HTML · CSS · JS)로 만들고, "AI 상담원"은 LLM(대형 언어 모델) 대신 **정해진 순서의 규칙(상태 기계)**으로 움직인다.

## 이유
- 비용 0원(요구 A10, AC-64). GitHub Pages로 링크 하나만 주면 면접관이 직접 눌러 볼 수 있다.
- 결과가 매번 같다. 그래서 "위급 놓침 0건 · 규정 밖 직접 답 0건"(AC-67 · 68)을 시험으로 증명할 수 있다.
- 하네스(규칙 · 넘김 · 기록)를 보여 주는 것이 목적이다. 모델의 말솜씨는 목적이 아니다.

## 대안
- LLM API 소량 사용: 대화가 자연스럽지만 비용이 생기고 결과가 매번 달라 시험이 어렵다.
- 내 PC의 공개 모델: 무료지만 면접관 화면에서는 돌릴 수 없다.

## 결과
- 자유로운 대화는 못 한다. 정해진 선택지 · 키워드 중심 대화가 된다.
- 실제 운영에서는 같은 규칙(하네스)을 LLM 앞뒤에 그대로 두고, 상담원 부분만 교체한다. 교체 지점은 `agent.js` 한 곳이다.
